Frequency: Weekly Monthly Quarterly Annually As Needed

1. Zoom Attendant Computer

▼
Weekly
  • Verify Zoom is updated to the latest version (Zoom auto-updates can fail silently)
  • Test the Zoom meeting link and confirm it connects properly before the meeting
  • Confirm the waiting room is enabled and functioning
  • Check that the correct co-hosts and attendant roles are assigned
  • Verify screen sharing is restricted to hosts/co-hosts only
  • Test audio/video feed from the attendant's perspective
Monthly
  • Restart the computer fully (not just sleep/wake) to clear memory and apply pending updates
  • Check Windows/macOS updates and install any pending security patches
  • Run a full antivirus/malware scan
  • Clear browser cache and temporary files
  • Verify the Zoom license status is active and not expiring (per S-413)
  • Confirm the Zoom account password is still working and known to authorized brothers
  • Test the internet connection speed — minimum recommended is 3–5 Mbps upload for stable video
Quarterly
  • Review who has access to the Zoom account credentials and update if needed
  • Change the Zoom meeting password per the congregation's password rotation schedule (reference S-287)
  • Verify Zoom meeting settings haven't been altered: waiting room, mute on entry, chat restrictions, recording disabled
  • Check that the computer's hard drive has at least 15–20% free space
  • Review and remove any unnecessary software or browser extensions
  • Confirm the computer's power settings won't cause it to sleep mid-meeting
Annually
  • Evaluate whether the computer hardware still meets Zoom's minimum requirements
  • Review the Zoom license renewal timeline (per S-413)
  • Confirm the congregation's Zoom account email is accessible and monitored

2. A/V Computer (Media Playback & Presentation)

▼
Weekly
  • Verify JW Library app is updated to the latest version
  • Confirm all meeting media for the week has been downloaded and is ready for playback (per S-144)
  • Test audio output levels through the Kingdom Hall sound system
  • Test video output to the monitors/displays — confirm resolution and aspect ratio are correct
  • Check all cable connections (HDMI, USB, audio) for secure fit
  • Confirm the correct meeting media is queued and in order
Monthly
  • Restart the computer fully
  • Install all operating system security updates
  • Run antivirus/malware scan
  • Clear temporary files and old meeting media no longer needed
  • Check that display/monitor firmware is current (if applicable)
  • Test the backup plan: know what to do if the primary computer fails mid-meeting (e.g., tablet backup, phone hotspot)
  • Verify audio mixer or sound board settings haven't drifted from the standard configuration
Quarterly
  • Inspect all physical cables for wear, fraying, or loose connections
  • Clean computer vents and fans to prevent overheating
  • Check that USB ports, HDMI ports, and audio jacks are all functioning
  • Verify the computer's date/time settings are correct (auto-sync enabled)
  • Review and remove any unauthorized software
  • Confirm the computer is NOT connected to personal accounts, cloud storage, or non-approved services
  • Test the backup media playback method (per S-127 guidelines for JW Library)
Annually
  • Evaluate hardware condition: battery health (if laptop), hard drive health, RAM adequacy
  • Consider whether the computer meets current minimum specs for JW Library and media playback
  • Review A/V setup against current S-261 hybrid meeting instructions for any configuration changes
  • Check monitor/display condition for dead pixels, brightness degradation, or burn-in

3. Passwords & Account Security

▼
Monthly
  • Verify all authorized brothers know the current Zoom meeting password
  • Confirm the Zoom host/co-host account passwords are stored securely (not on sticky notes at the KH)
  • Check that the JW Hub account for the congregation is accessible
  • Verify jw.org congregation account access is functioning
Quarterly
  • Rotate the Zoom meeting passcode
  • Rotate the Zoom account login password
  • Review who has access to each account and remove anyone no longer serving in that role
  • Change the Kingdom Hall Wi-Fi password if one exists
  • Update any shared passwords for the A/V or Zoom computers if applicable
As Needed (Role Changes)
  • Immediately update all passwords when a brother is removed from or added to the attendant/A/V role
  • Transfer account ownership if the Zoom account holder changes assignments
  • Update JW Hub access if elders or servants change

4. Cybersecurity (Reference S-287)

▼
Weekly
  • Confirm the Kingdom Hall computers are NOT being used for personal browsing, email, or downloads
  • Verify no unauthorized USB drives or devices have been connected
Monthly
  • Ensure antivirus definitions are up to date
  • Confirm the operating system firewall is enabled
  • Check that the computers auto-lock after a period of inactivity
  • Verify no unfamiliar software has been installed
Quarterly
  • Review the S-287 Cybersecurity Guidelines to ensure continued compliance
  • Confirm the Kingdom Hall network has a strong, unique Wi-Fi password using WPA2 or WPA3 encryption
  • Verify that the router firmware is up to date (if the congregation manages it)
  • Check that Bluetooth and file sharing are disabled on the Kingdom Hall computers when not needed
  • Confirm that no congregation data or personal information is stored on the computers unnecessarily
Annually
  • Conduct a full cybersecurity review against S-287 guidelines
  • Evaluate whether any new threats or guidelines have been published on JW Hub
  • Review the Disaster Preparedness Program as it relates to data and IT recovery
  • Assess whether the congregation's IT setup needs any hardware or configuration upgrades

5. Internet & Network

▼
Monthly
  • Test internet speed and stability (minimum 3–5 Mbps upload for Zoom)
  • Verify the VoIP telephone system is working (per Kingdom Hall VoIP Telephone Setup document)
  • Confirm the router is functioning and not overheating
Quarterly
  • Restart the router/modem to clear any connection issues
  • Check for ISP service advisories or outages in the area
  • Review the internet plan to ensure it meets the congregation's bandwidth needs (especially if multiple devices stream simultaneously during hybrid meetings)

Quick-Reference Summary

Frequency Key Actions
Weekly Test Zoom + A/V before meetings, verify media is ready, check connections
Monthly OS updates, antivirus scans, restart computers, test internet speed, verify passwords work
Quarterly Rotate passwords, inspect cables/hardware, review account access, clean equipment
Annually Full hardware evaluation, cybersecurity audit against S-287, review all JW Hub documentation for updates
